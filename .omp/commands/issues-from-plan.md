# /issues-from-plan — break an approved plan into GitHub issues

Role: **orchestrator**.

Arguments: `$ARGUMENTS` (optional plan path).

## Run it

1. `read skill://issues-from-plan` and follow it.
2. Create one independently-grabbable GitHub issue per vertical slice, each
   carrying its Gherkin scenarios and acceptance criteria. Requires the `github`
   MCP server (see `.omp/mcp.json`) or `gh`.
