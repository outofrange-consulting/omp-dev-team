# Single source of truth for filesystem-walk exclusions used by the
# `codebase-recon` agent's inventory step (the `file_inventory` envelope field,
# security-primitives-contract 1.2.0+) when the target is NOT a git working
# tree. Two sections, each with one entry per line.
#
# Upstream ships this as input to a `scripts/recon-inventory.sh`; that script was
# not ported, so the agent walks the tree itself and reads this file for the
# exclusion set. Keeping the list here (rather than inline in the agent prompt)
# is what makes the walk deterministic across runs.
#
# The git-ls-files branch does NOT consult this file — git's own .gitignore +
# working-tree rules are already authoritative. This file drives ONLY the
# non-git fallback.
#
# Format:
#   - Lines starting with `#` are comments.
#   - Blank lines are ignored.
#   - Two section markers: `# prefix:` and `# filename:`
#   - Under `# prefix:` each line is a directory name to prune during descent.
#     Trailing slash is recommended (matches the spec) but not required; the
#     script normalises by stripping any trailing slash before matching.
#   - Under `# filename:` each line is a filename to drop wherever it appears.
